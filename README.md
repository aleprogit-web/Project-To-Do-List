# To-Do List

Um aplicativo de lista de tarefas desenvolvido com HTML, CSS e JavaScript, criado para praticar conceitos de desenvolvimento web e manipulação do DOM.

## 🇧🇷 Português

### Sobre o projeto

O To-Do List é um aplicativo simples para organizar tarefas do dia a dia.

O projeto foi desenvolvido durante meus estudos de JavaScript, com foco em manipulação do DOM, eventos, arrays, objetos e armazenamento de dados no `localStorage`.

### Funcionalidades

- Adicionar tarefas
- Definir uma data opcional para cada tarefa
- Marcar tarefas como concluídas
- Editar tarefas
- Excluir tarefas individualmente
- Excluir todas as tarefas
- Marcar tarefas como favoritas
- Filtrar tarefas por:
  - Todas
  - Pendentes
  - Concluídas
  - Favoritas
  - Todas do dia
- Visualizar um resumo das tarefas do dia
- Navegar entre os dias no resumo
- Personalizar o nome exibido no aplicativo
- Limpar tarefas concluídas
- Alternar entre modo claro e modo escuro
- Salvar tarefas no `localStorage`
- Layout responsivo para dispositivos móveis

### Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Day.js
- LocalStorage

### Objetivo

Este projeto foi criado como uma forma de praticar JavaScript e desenvolver uma aplicação completa utilizando HTML, CSS e JavaScript.

## 🇺🇸 English

### About the project

To-Do List is a simple task management application for organizing everyday tasks.

The project was developed while studying JavaScript, focusing on DOM manipulation, events, arrays, objects, and data storage using `localStorage`.

### Features

- Add tasks
- Set an optional date for each task
- Mark tasks as completed
- Edit tasks
- Delete individual tasks
- Delete all tasks
- Mark tasks as favorites
- Filter tasks by:
  - All
  - Pending
  - Completed
  - Favorites
  - Today's tasks
- View a daily task summary
- Navigate between days in the summary
- Customize the name displayed in the application
- Clear completed tasks
- Toggle between light and dark mode
- Store tasks using `localStorage`
- Responsive layout for mobile devices

### Technologies

- HTML5
- CSS3
- JavaScript
- Day.js
- LocalStorage

### Purpose

This project was created as a way to practice JavaScript and build a complete application using HTML, CSS, and JavaScript.
